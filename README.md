# Analyse du Comportement des Clients et Optimisation des Campagnes Marketing

## Présentation du projet

Ce projet vise à analyser les comportements des clients afin d'orienter les campagnes marketing et d'améliorer la prise de décision.

## Objectifs
- Explorer et nettoyer les données clients.
- Identifier les comportements et tendances.
- Segmenter les clients selon les données disponibles.
- Suivre les indicateurs marketing à l'aide de visualisations.

## Outils utilisés
- **Python :** Pandas pour le traitement et l'analyse des données.
- **PostgreSQL :** requêtes SQL pour l'exploitation des données.
- **Power BI :** création de tableaux de bord interactifs.

## Livrables
- Analyse exploratoire des données.
- Segmentation des clients.
- Tableau de bord interactif des indicateurs marketing.
